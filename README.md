# EchoMind

EchoMind is an AI-powered thought and decision analyzer built with Vanilla JavaScript.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Gemini API
- LocalStorage

## Core Features

- AI thought analysis
- Understand mode
- Organize mode
- Decide mode
- Action board
- Analysis history
- Interactive dashboard

## Project Structure

- `index.html` - Main application entry
- `css/` - Styles
- `js/` - Application logic
- `js/components/` - UI components
- `assets/` - Images and icons
